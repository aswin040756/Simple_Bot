Creating a Simple Greeting Bot using If-Else Statement and  Simple Calculator using Simple Python Programming
# Smart Calculator and Friendly Greeting Bot

## About the Project

This is a beginner-level Python project that combines
a calculator and a greeting bot.

## Features

### Greeting Bot
- Accepts the user's name
- Displays a personalized greeting
- Uses f-strings
- Uses if-else conditions

### Smart Calculator
- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero handling
